# Site estático 

# Visão Geral ⭐ 
Atividade realizada para a matéria de Linguagens de Marcação, do curso técnico em Desenvolvimento de Sistemas do SENAI. 
O objetivo dessa atividade foi gerar um site simples (apenas com html e css) para um restaurante. Eu e minha equipe escolhemos o restaurante Maria Augusta Bar, localizado na Zona Sul de São Paulo. 

# Requisitos 📄
- Visual Studio Code
- Extensão **Live Server** instalada no VS Code

# Como rodar o projeto 💻
1. Baixe o projeto
2. Extraia a pasta
3. Abra o projeto no Visual Studio Code
4. Abra o arquivo `index.html`
5. Clique com o botão direito do mouse no arquivo
6. Selecione a opção **Open with Live Server**
